Sambung sumber baharu

🟢WhatsApp Business PlatformCloud API rasmi — setiap mesej masuk jadi lead›
  1. Nombor perniagaan anda mesti didaftarkan pada WhatsApp Business Platform (Cloud API) dan disambung ke app Meta Dyno. App WhatsApp Business biasa di telefon tidak mempunyai API untuk membaca mesej — untuk itu guna Tambah lead manual.
  2. Di Meta Business Suite → WhatsApp Manager, salin Phone number ID.
  3. Masukkan token akses (System User) yang boleh mengakses nombor itu. Token hanya digunakan sekali untuk membuktikan pemilikan dan tidak disimpan.
URL webhook (ditetapkan sekali oleh pentadbir dalam app Meta Dyno):
Ⓜ️Meta Lead AdsBorang Facebook & Instagram — lead masuk serta-merta›
  1. Dapatkan Page ID Facebook Page yang menjalankan iklan borang (Page → About / Page transparency).
  2. Dapatkan Page access token untuk app Meta Dyno dengan kebenaran leads_retrieval, pages_manage_metadata, pages_show_list dan pages_read_engagement.
  3. Kami sahkan token, langgan webhook leadgen untuk Page itu, dan simpan token dalam bentuk tersulit untuk mengambil butiran setiap lead.
